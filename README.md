  
> **"Turning Traditions into Unforgettable Memories"**

Radhey Events Management is a **full-stack SaaS platform** built to simplify and modernize booking workflows for **luxury Indian weddings and events**.  

Developed for a real client (**Pithe Brothers, Amravati**), this platform combines a **premium UI/UX** with a scalable **MERN-based architecture**.

---

## 🚀 Live Demo  

- 🌐 **Website**: https://radhe-event-management-8b9y.vercel.app/  
- ⚙️ **Backend API**: https://radhey-events-api.onrender.com/  

---

## ✨ Features  

- 🎨 **Premium UI Design**  
  Elegant *Pink & Gold theme* tailored for high-end Indian weddings  

- 🧩 **Multi-Step Booking Wizard**  
  4-step seamless booking flow with **real-time cost estimation**  

- 🛠️ **Customizable Services**  
  Catering, DJ, Lighting & more with dynamic pricing  

- 📊 **Admin Dashboard**  
  Manage bookings & track revenue in real-time  

- ⚡ **Fast & Scalable**  
  Built using modern full-stack architecture  

- 🔍 **SEO Optimized**  
  Google indexed with proper metadata, sitemap & robots  

- 🚀 **Production Ready**  
  CI/CD enabled using GitHub, Vercel & Render

## 🛠️ Local Setup  

### 1️⃣ Clone Repository  
```bash
git clone https://github.com/vansh708/radhe_event_management.git
```

### 2️⃣ Frontend Setup  
```bash
npm install
npm run dev
```

### 3️⃣ Backend Setup  
```bash
cd backend
npm install
node server.js
```
